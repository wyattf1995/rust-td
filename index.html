Controls: Keys 1-8 select towers, click to place. Space starts wave. Q freeze, W gold rush, E artillery. U upgrade, S sell, T targeting, Z undo. Escape to pause.

Neon Command is a visual tower defense game rendered to a canvas element. Screen readers cannot access the game interface. Keyboard shortcuts are available for most actions, but tower placement requires a pointer device.
